# 배포

1. **점검**: 아래 셋 중 하나라도 실패하면 멈추고 사용자에게 보고한다.
   - script 부분만 뽑아서 `node --check`를 돌린다.
   - `python -m http.server 8765`를 띄우고 `/?test`를 열어 콘솔에 `self-check done`이 뜨는지, assert 실패가 없는지 본다.
   - 브라우저에서 마우스로 한 번 던지고, 벽 닦기를 한 번 해서 스크린샷으로 확인한다.
2. **비밀값 검사**: `index.html`에 비공개 키나 토큰이 없는지 grep으로 찾는다. `sk_`, `secret`, `token` 같은 패턴을 본다.
3. **사용자 확인**: "Vercel production에 배포할까요?"라고 묻고 답을 기다린다. 공개되는 작업이므로 매번 묻는다.
4. 배포는 `vercel --prod`로 한다. 처음 배포할 때는 로그인과 프로젝트 연결을 사용자가 직접 한다.
5. 배포된 URL을 열어 카메라 권한 요청이 HTTPS에서 정상으로 뜨는지 확인한다. URL을 사용자에게 알려 준다.
