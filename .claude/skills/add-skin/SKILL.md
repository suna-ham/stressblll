# 스킨 추가

1. `index.html`의 `drawTomato()` 구조를 확인한다. 굴절 → 색 입히기 → 속빛 → 기포 → 반사 → 윤곽 순서로 그린다.
2. 처음으로 두 번째 스킨을 추가할 때만 `const SKINS = { tomato: {...}, egg: {...} }` 객체를 만든다. 각 스킨은 색 구성(③ 단계 그라디언트), 즙과 씨앗 색, 꼭지를 그리는 함수(있을 때만), `premium` 여부를 갖는다. 스킨이 하나뿐일 때는 이 객체를 만들지 않는다.
3. 얼굴 사진 스킨은 ③ 단계에서 `drawImage(faceImg)`로 칠한다. 사진은 `FileReader`와 `createObjectURL`로 브라우저 안에서만 다룬다. 서버로 보내지 않는다.
4. 프리미엄 스킨은 결제 전에 흐린 미리보기와 자물쇠를 보여 준다. 고르면 결제 권유 창이 뜬다. 던지기 동작 자체는 막지 않는다.
5. 터지는 느낌은 스킨마다 달라야 한다. 계란은 노른자, 물풍선은 투명한 물방울, 슬라임은 끈적하게 늘어나는 식이다. `updateJuice()`의 방울 색과 크기를 스킨 값으로 바꿔 끼운다.
6. 브라우저에서 스킨마다 한 번씩 던져 보고 스크린샷으로 확인한다. `?test`도 통과해야 한다.
