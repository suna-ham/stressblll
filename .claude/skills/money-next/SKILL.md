# 다음 수익 작업 하나 하기

1. `BUSINESS.md`와 `CLAUDE.md`를 읽는다.
2. 7절 체크리스트에서 체크되지 않은 **첫 번째 항목 하나만** 고른다. 사용자가 다른 항목을 지정했으면 그 항목을 한다.
3. 외부 값이 필요한 항목이면 먼저 사용자에게 묻고 기다린다. 결제 링크, 팁 링크, 분석 도메인, 스토어 상품 ID 같은 값이다. 값을 지어내지 않는다.
4. `index.html`에 최소한으로 구현한다. 지켜야 할 것:
   - 무료 핵심 기능(던지기, 터지기, 닦기)은 그대로 동작해야 한다.
   - 결제 권유는 10번째 던지기 후 한 번, 리셋할 때 한 번만 띄운다. 이미 결제한 사용자에게는 띄우지 않는다.
   - 프리미엄 잠금 해제 상태는 `localStorage['premium']`에 저장한다. 라이선스 검증은 결제사가 제공하는 공개 API만 쓴다.
   - 분석 이벤트 이름은 BUSINESS.md 4절에 있는 이름만 쓰고, 이미지 데이터는 싣지 않는다.
5. 확인한다: `node --check`로 문법을 보고, `?test` 자가 점검을 돌리고, 브라우저에서 해당 흐름을 직접 눌러 본 뒤 스크린샷을 남긴다.
6. BUSINESS.md 체크리스트의 해당 항목을 `[x]`로 바꾼다. 수익 관점에서 다음으로 할 일을 한 줄로 제안한다.
